Як підключити Remont

Найкраще Remont працює в Claude: реальні ціни магазинів із посиланнями, збережений план, який можна правити в чаті, планування і 3D. У ChatGPT теж працює, але з обмеженнями.

Адреса сервера
https://remont-mcp.wrpzdm9jmt.workers.dev/mcp
Без реєстрації та ключів.

Claude — рекомендуємо

  1. Відкрийте claude.ai і увійдіть.
  2. Перейдіть у Налаштування → Конектори (у нових версіях: Customize → Connectors).
  3. Натисніть «Додати власний конектор» (Add custom connector) або «+».
  4. Назва: Remont. URL: адреса сервера вище. OAuth і ключі не потрібні — натисніть «Додати».
  5. У чаті відкрийте меню «+» / інструменти й перевірте, що Remont увімкнено. Далі просто запитайте про ремонт.

Безкоштовний тариф Claude: один власний конектор. Pro, Max, Team, Enterprise: скільки завгодно. У Team і Enterprise спершу його додає власник у налаштуваннях організації.

Перевірка, що працює

Сервер підключено?

Використай Remont: покажи профіль країни Польща

✓ Claude викликає інструмент Remont і називає валюту (PLN) і магазини (Castorama, Leroy Merlin, OBI).

План відкривається?

Використай Remont: склади план ремонту двокімнатної 50 м² у Білостоці — вітальня 20, спальня 13, кухня 8, ванна 4, передпокій 5. Роблю сам, ванну — майстер.

✓ З'являється інтерактивний план із вкладками «План / Матеріали / Інструменти / Планування» і цінами магазинів.

ChatGPT

Потрібен платний тариф ChatGPT: на безкоштовному власних конекторів немає. На деяких тарифах ChatGPT дозволяє лише читання: план показується, а збереження і правки не працюють.

  1. Відкрийте chatgpt.com на комп'ютері.
  2. Нове меню: Plugins → + → Add custom MCP server. Старе меню: Settings → Apps & Connectors → Advanced settings → увімкніть Developer mode, потім Apps & Connectors → Create.
  3. Name: Remont. MCP Server URL: адреса сервера вище. Authentication: No authentication. Якщо спитає — позначка «I trust this application» → Create.
  4. У новому чаті натисніть + під полем вводу (або More → Developer mode) і виберіть Remont. Починайте запит зі слів «Використай Remont: …».
  5. Якщо вікно плану не з'явилося, попросіть «дай посилання на сторінку плану» — у кожній відповіді є посилання на цей самий план у браузері.

Claude Code, Cursor, VS Code та інші MCP-клієнти

Claude Code

claude mcp add --transport http remont https://remont-mcp.wrpzdm9jmt.workers.dev/mcp

mcp.json

{
  "mcpServers": {

Якщо щось не так

Немає пункту «Add custom connector» / «Add custom MCP server»

Тариф не дозволяє власні конектори (або в ChatGPT вимкнено Developer mode).

Помилка під час додавання

Адреса має закінчуватися на /mcp, без пробілів; без автентифікації.

ШІ відповідає без Remont

Увімкніть конектор у цьому чаті (меню +) і почніть зі слів «Використай Remont: …». Нові конектори з'являються лише в нових чатах.

План текстом, без вікна

Попросіть посилання на сторінку плану — відкриється той самий інтерактивний план.
